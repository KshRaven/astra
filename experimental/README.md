# Experimental

Ideas and frameworks that are **not part of the running panel**. Nothing here is imported by `astra`, packaged by
`pip install .`, or started by any command. Expect it to change or disappear.

| Folder | What it is |
| --- | --- |
| `paneldb/` | A design sketch for a future panel database: users and roles, credentials, audit trail, notifications, app registry, settings and the mail queue. No engine yet. |
